## Events and Competitions

### Technical Arena

1. Paper Presentation (1 to 3 members)
   - Format: IEEE standard format, 7 minutes presentation + 3 minutes Q&A
   - Scope: Electrical engineering, green energy, electronics, AI, robotics and interdisciplinary domains
   - Cash Prizes: 1st: Rs. 500, 2nd: Rs. 400, 3rd: Rs. 300

2. TechMain - Technical Quiz (Individual)
   - Format: 60 questions: Round 1 (30 Written MCQs in 25 mins) + Round 2 (30 Oral Speed Trivia questions)
   - Rules: Zero negative marking
   - Cash Prizes: 1st: Rs. 500, 2nd: Rs. 400, 3rd: Rs. 300

3. Debugging Circuit (2 to 4 members)
   - Format: Hands-on DC hardware debugging, breadboards, digital multimeters, component fault rectification
   - Requirements: Teams must bring their own laptop and charger (Internet permitted)
   - Cash Prizes: 1st: Rs. 500, 2nd: Rs. 400, 3rd: Rs. 300

### Non-Technical Arena

4. Robo Relay (2 members)
   - Format: Blindfolded obstacle challenge: 1 blindfolded performer + 1 vocal-only instructor (Strictly no physical contact)
   - Rules: 3-strike boundary penalty rule
   - Cash Prizes: 1st: Rs. 500, 2nd: Rs. 400, 3rd: Rs. 300

5. Mission Impossible (2 members)
   - Format: 5 progressive campus clue checkpoints concluding in a solo laptop cipher decryption trial
   - Rules: Maximum 3 attempts per clue checkpoint
   - Cash Prizes: 1st: Rs. 500, 2nd: Rs. 400, 3rd: Rs. 300

6. Electro Enigma (2 members)
   - Format: 3 rounds: Connection puzzles, visual tech memory, and pop-culture electronics trivia
   - Rules: 10-second timer per question, zero negative marking
   - Cash Prizes: 1st: Rs. 500, 2nd: Rs. 400, 3rd: Rs. 300

## Technical Architecture

- Frontend: Semantic HTML5, Vanilla CSS3, Modular JavaScript
- 3D Interactive ID Card: Three.js WebGL engine with custom Verlet rope physics and gunmetal hardware
- Audio Synthesis: Real-time Web Audio API synthesizer for sci-fi electric sound effects
- Event Simulators: Interactive sandboxes for all 6 events
- Responsive Layout: Optimized for mobile, tablet, and ultra-wide desktop viewports
- Fonts: Inter, Geist Mono, Outfit (Google Fonts)
